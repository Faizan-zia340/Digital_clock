# Digital Clock

A clean digital clock app built with HTML, CSS, and JavaScript.

## Features
- Live time display
- Date and time updates in real time
- Clean, modern interface
- Responsive layout

## Tech Stack
- HTML
- CSS
- JavaScript

## Run Locally
1. Clone the repository
2. Open `index.html` in your browser

## Description
This project shows a real-time digital clock with a simple and polished UI. It is a beginner-friendly front-end project that demonstrates JavaScript time updates and DOM manipulation.
